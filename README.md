# Planilha de Cálculos e Fórmulas

Exercício de planilha com cinco abas: cálculos matemáticos, conversões de unidades, conversão de moedas, porcentagens e composição de produtos.

## Abrir e explorar

Abra `planilha-calculos-formulas.xlsx` no Microsoft Excel ou LibreOffice Calc. As abas contêm instruções e exemplos; nas abas de moedas, atualize manualmente as cotações de referência antes de usar os resultados. Valores de cotação são exemplos de uma data não especificada, não cotações atuais.

Esta planilha é material didático e não deve ser usada como orientação de formulação química ou de segurança de produtos.

Metadados e nome pessoal presentes na cópia original foram removidos.
